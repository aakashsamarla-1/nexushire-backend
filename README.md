
# Enterprise RAG Assistant

AI + Spring Boot + PostgreSQL starter project.

## Features

- Spring Boot REST API
- PostgreSQL
- JPA
- Swagger
- AI Service Layer
- Docker PostgreSQL Setup
- PDF Processing Dependency
- Security Dependency

## Run PostgreSQL

docker compose up -d

## Run Application

Run:
RagAssistantApplication.java

## Test APIs

GET:
http://localhost:8080/api/hello

POST:
http://localhost:8080/api/ask?question=What is AI?

Swagger:
http://localhost:8080/swagger-ui.html
